# Python IT Automation Scripts

A collection of Python scripts built to automate everyday system administration and IT support tasks.

#Projects
1. [Active User Tracker](./01-active-user-tracker) — Parses system login/logout event logs to generate a live report of active users per machine.
2. [Linux User Provisioning](./02-linux-user-provisioning) — Automates bulk Linux account creation and random password generation from CSV files.
