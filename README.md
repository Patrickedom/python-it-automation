# Python IT Automation Scripts

A collection of Python scripts built to automate everyday system administration and IT support tasks.

## Projects

1. **[Active User Tracker](https://github.com/Patrickedom/python-it-automation/tree/main/01-active-user-tracker)** — Parses system login/logout event logs to generate a live report of active users per machine.
2. **[Linux User Provisioning](https://github.com/Patrickedom/python-it-automation/tree/main/02-linux-user-provisioning)** — Automates bulk Linux account creation and random password generation from CSV files.

## Requirements

* Python 3.6 or higher (uses standard libraries only; no external package dependencies required).
